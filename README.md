## <img src="https://raw.githubusercontent.com/Tarikul-Islam-Anik/Animated-Fluent-Emojis/master/Emojis/Objects/Gear.png" width="20"/> &nbsp;What I build

I build **AI agents, automation pipelines, and the full-stack products around them** — systems
that run on a schedule, make decisions, and put results somewhere a human can act on them.

Most of my work looks like this: an API or a scraper feeds a scoring model, the model writes to
a database or an Airtable, and a dashboard or a Slack message closes the loop. Multi-agent
orchestration with `n8n` and `make.com`, custom Python pipelines when the no-code ceiling hits,
and `FastAPI` + `Next.js` when it needs a real product around it.
